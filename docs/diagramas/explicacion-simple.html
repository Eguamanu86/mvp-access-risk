MIS-312 · MLOps

Cómo funciona la IA del MVP de riesgo de acceso

Explicación simple, bloque por bloque.

Usa las flechas ← → o los botones para navegar.
1Entrada

Llega el intento de login

El sistema recoge 5 datos del intento:

  • ¿El dispositivo es de confianza?
  • ¿Cuántos intentos fallidos hubo?
  • ¿Se movió muy lejos y muy rápido?
  • ¿A qué hora entró?
  • ¿A qué velocidad se desplazó?
Como un portero: mira quién llega antes de decidir si abre.
2Features

Traducir los datos

El modelo convierte todo a números del 0 al 1.

  • Así todos los datos quedan en la misma escala.
  • “Dispositivo desconocido” = 1 · “de confianza” = 0.
  • Se pueden comparar de forma justa.
Como una receta: primero se miden todos los ingredientes igual.
3Modelo

La calculadora de riesgo

El modelo combina los datos con pesos que aprendió solo.

  • Cada dato aporta más o menos según su peso.
  • La suma de todo da un solo número: z.
Como una receta: cada ingrediente pesa distinto en el resultado.
4Decisión

¿Cuánto riesgo hay?

El número se convierte en un puntaje de 0 a 1.

  • Puntaje bajo → dejar entrar.
  • Puntaje medio → pedir segundo factor (2FA).
  • Puntaje alto → bloquear.
  • La IA solo opina; el sistema (backend) decide.
Como un semáforo: verde, amarillo o rojo según el puntaje.
5Mejora

Aprender de los resultados

Cada decisión se guarda y luego se revisa.

  • Se marca si en realidad fue fraude o legítimo.
  • Si los datos cambian mucho (drift) → se reentrena.
  • Solo se adopta el modelo nuevo si es mejor.
Como estudiar los errores: aprender de lo que pasó para mejorar.

En una frase

El sistema recoge los datos del intento, calcula un puntaje de riesgo, decide qué hacer y aprende de lo que pasó para mejorar.
